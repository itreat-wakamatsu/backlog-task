Backlog API キーの設定

初回のみ必要な設定です。Backlog の個人設定から API キーを発行して拡張機能に登録してください。

1
Backlog にログインして個人設定を開く 右上のアイコン →「個人設定」をクリック
2
API キーを発行する 左メニューの「API」→「メモ」に任意の名前（例: Chrome拡張）を入力 →「登録」をクリック
3
APIキーをコピーする 生成されたキーをコピーしてください
4
拡張機能に貼り付けて保存 拡張機能を開くと初期設定画面が表示されます。スペースID（例: itreatinc）と API キーを入力して「保存」をクリック

AI自動入力の設定

APIキーを設定すると、選択テキストから件名・詳細・担当者・期日などを自動入力できます。 GoogleのGeminiまたはOpenAIのGPTが利用できます（どちらか一方でOK）。

🟣 Google Gemini（無料枠あり）
1
Google AI Studio を開く Google AI Studio を開く →
2
「APIキーを作成」をクリック プロジェクトを選択してキーを発行します
3
拡張機能の設定に貼り付け 「設定 → AI自動入力」で Gemini を選択し、APIキー欄に貼り付けて保存
🟢 OpenAI（GPT）
1
OpenAI Platform を開く OpenAI Platform を開く →
2
「+ Create new secret key」をクリック 表示されたキーをコピーしてください（以降は再表示されません）
3
拡張機能の設定に貼り付け 「設定 → AI自動入力」で OpenAI を選択し、APIキー欄に貼り付けて保存

ヒント

  • Google ドキュメント テキスト選択後に Ctrl+C（Mac: ⌘C）でコピーしてからフォームを開くと、詳細欄への自動反映がより確実です
  • URLごとのプロジェクト記憶 フォーム上の「このページでは常にこのプロジェクトを使用する」にチェックを入れると、次回から自動適用されます
  • カスタム指示 「設定 → AI自動入力 → カスタム指示」に独自のルール（プロジェクト・担当者の振り分けなど）を記述するとAIがそれを最優先で適用します
