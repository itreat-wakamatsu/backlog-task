プライバシーポリシー

拡張機能: Backlog Quick Add
施行日: 2026年3月26日

本プライバシーポリシーは、ブラウザ拡張機能「Backlog Quick Add」（以下「本拡張機能」）が、利用時にどのように情報を取り扱うかを説明するものです。 本拡張機能は、閲覧中のウェブページから選択したテキストやページ情報を用いて Nulab Backlog（以下「Backlog」）へ課題を登録すること、および任意の入力補助のための生成 AI API の利用を可能にすることを目的として提供されています。

概要

  • お客様の個人情報を販売しません。
  • 本拡張機能内に広告やアクセス解析用のトラッカーを組み込んでいません。
  • 本拡張機能の公開者が、課題作成とは無関係な目的で独自のサーバーにお客様のデータを収集する仕組みはありません。通信はお客様のブラウザから、Backlog またはお客様が任意で利用する第三者の API（OpenAI、Google）へ直接行われます。
  • 設定・API キー・下書き・キャッシュなどは、原則として chrome.storage.local を用いて端末内（お使いの Chrome プロファイル内）に保存されます。本拡張機能は chrome.storage.sync による Chrome アカウントへの同期を利用しません。

本拡張機能が取り扱う情報

本拡張機能は、機能の提供に必要な範囲でのみデータを処理します。

  • 閲覧中のウェブページに関する情報（お客様が本拡張機能を操作したとき）
    ツールバーアイコン、右クリックメニュー、キーボードショートカットなどで本拡張機能を起動した際、そのときアクティブなタブについて、選択中のテキスト、ページの URL、ページタイトルを読み取り、課題の下書きやフォームに反映します。すべてのタブの閲覧履歴を常時収集するものではありません。
  • お客様が設定・入力した情報
    Backlog のスペース URL、Backlog API キー、表示や動作に関する設定、課題フォームへの入力内容、下書き、URL ごとのデフォルトプロジェクトの対応、任意で設定する OpenAI または Google（Gemini）の API キーと AI 関連設定などです。
  • Backlog API から取得した情報（キャッシュ）
    プロジェクト、課題種別、優先度、ユーザー（担当者・メンション用）など、課題作成フォームに必要な一覧データを Backlog の API から取得し、端末内にキャッシュします。定期的な更新（アラーム）およびお客様の手動更新に応じて再取得することがあります。
  • クリップボードに関する処理
    一部のページでは、通常の方法で選択テキストを取得できない場合に、コピー操作に伴うテキストの読み取りを用いて選択内容を補完します。課題の添付として、お客様が貼り付けた画像データを扱うことがあります。

Chrome のストレージ

本拡張機能が保存するデータの多くは chrome.storage.local に格納され、端末内に留まります。Chrome の設定から拡張機能のデータを消去する、本拡張機能をアンインストールする、または本拡張機能内の設定・フォームを編集・削除することにより、内容を変更または削除できます。

ネットワーク通信と第三者

本拡張機能は、次の通信を行うことがあります。いずれも HTTPS を用います。

Backlog（Nulab）

お客様が指定したスペースのドメイン（例: *.backlog.com、*.backlog.jp、*.backlogtool.com）に対し、API キー認証のもと REST API 経由で、課題の登録、マスタ情報の取得・検証などを行います。 取り扱いは Nulab のプライバシーポリシー および Backlog の利用規約等に従います。

OpenAI（任意）

お客様が OpenAI の API キーを設定した場合、課題の件名・詳細などの入力補完のため、お客様が選択したテキストやページ情報などを api.openai.com に送信することがあります。 取り扱いは OpenAI のポリシー に従います。

Google（Gemini API、任意）

お客様が Google の API キーを設定した場合、同様の入力補完のため、generativelanguage.googleapis.com にデータを送信することがあります。 取り扱いは Google のプライバシーに関する文書（例: Google プライバシー ポリシー）に従います。

これらの通信に伴い、各サービス提供者が IP アドレス等の標準的な技術情報を受け取る場合があります。詳細は各提供者のポリシーをご参照ください。

リモートコード

本拡張機能は、インターネット上から JavaScript 等のプログラムコードを取得して実行する用途には使用しません。API から受け取るのはデータ（例: JSON）であり、処理はパッケージに同梱されたコードのみで行います（Manifest V3 に準拠した実装です）。

権限とその理由（マニフェスト）

  • activeTab — お客様が本拡張機能を操作した直後のアクティブなタブについて、選択テキストや URL・タイトルを読み取るため。
  • alarms — Backlog のマスタ情報キャッシュを定期的に更新するため。
  • clipboardRead / clipboardWrite — 一部のページで選択テキストを取得する際のコピー処理、または貼り付けに伴うクリップボードの扱いのため。
  • contextMenus — 右クリックメニューから課題作成などを呼び出すため。
  • scripting — コンテンツスクリプトで取得できない場合に限り、お客様の操作に応じてアクティブなタブ内で選択テキスト取得に必要な最小限の処理を行うため。
  • sidePanel — 課題作成フォームをサイドパネルに表示するため。
  • storage — 設定、API キー、下書き、キャッシュなどの保存・読み込みのため。
  • windows — 設定により課題作成画面をポップアップウィンドウで開くため。
  • コンテンツスクリプト（マニフェスト宣言） — 宣言された一致パターンに基づき、ページ上で選択テキストの取得などに協力します。Chrome のインストール画面では「すべてのウェブサイト上のデータの読取りと変更」などと表示されることがありますが、これは注入範囲に関する表示です。本拡張機能は、任意オリジンへの広範なネットワークアクセスを付与する host_permissions としての <all_urls> は要求していません。
  • ホスト権限 — 上記の Backlog スペース、および任意設定時の OpenAI / Google（Gemini）API エンドポイントへの通信のため。

データの保存期間

端末内のデータは、お客様が Chrome で拡張機能のデータを消去する、本拡張機能をアンインストールする、または本拡張機能内で編集・削除するまで保持されます。Backlog に登録された課題の保持は Backlog 側の設定および契約に従います。

お子様について

本拡張機能はお子様を対象としたものではなく、故意にお子様から個人情報を収集することはありません。

本ポリシーの変更

本拡張機能の動作や要件の変更に伴い、本プライバシーポリシーを更新することがあります。更新時には冒頭の施行日を改訂します。

Privacy Policy

Extension: Backlog Quick Add
Effective date: March 26, 2026

This Privacy Policy describes how the Backlog Quick Add browser extension (“Extension”) handles information when you use it. The Extension helps you create issues in Nulab Backlog (“Backlog”) using text you select on web pages and related page metadata, and optionally offers AI-assisted field completion via third-party APIs.

Summary

  • We do not sell your personal information.
  • We do not run advertising or analytics trackers inside the Extension.
  • The publisher does not operate a separate backend to collect your data for purposes unrelated to issue creation. Network requests are made from your browser directly to Backlog and, if you opt in, to OpenAI or Google APIs.
  • Settings, API keys, drafts, and caches are stored primarily in chrome.storage.local on your device (within your Chrome profile). The Extension does not use chrome.storage.sync.

Information the Extension processes

The Extension processes data only as needed to provide its features:

  • Web page context when you invoke the Extension
    When you use the toolbar button, context menu, or keyboard shortcut, the Extension reads the currently active tab’s selected text, URL, and page title to prefill a draft issue form. It does not continuously collect your full browsing history.
  • Information you configure or enter
    For example: your Backlog space URL, Backlog API key, UI and behavior settings, form fields and drafts, URL-to-default-project mappings, and—if you choose—OpenAI or Google (Gemini) API keys and AI-related settings.
  • Data fetched from Backlog (cached locally)
    Project lists, issue types, priorities, users (for assignees and mentions), and similar data are retrieved via the Backlog API and cached on your device. The Extension may refresh this data on a schedule (alarms) or when you request a refresh.
  • Clipboard-related handling
    On some pages where ordinary selection APIs are insufficient, the Extension may use copy-related flows to capture selected text. For attachments, the Extension may handle images you paste into the form.

Chrome storage

Most persisted data is stored with chrome.storage.local and remains on your device. You can remove or change it by clearing extension data in Chrome, uninstalling the Extension, or editing/deleting content inside the Extension.

Network requests and third parties

The Extension may make the following requests over HTTPS:

Backlog (Nulab)

To your configured Backlog host (e.g. *.backlog.com, *.backlog.jp, *.backlogtool.com), using your API key, to create issues, validate credentials, and fetch or refresh master data. Processing is governed by Nulab’s privacy policy and Backlog’s terms.

OpenAI (optional)

If you configure an OpenAI API key, the Extension may send selected text, page metadata, and related context to api.openai.com to suggest issue fields. See OpenAI’s policies.

Google (Gemini API, optional)

If you configure a Google API key, the Extension may send similar context to generativelanguage.googleapis.com. See Google’s privacy documentation (e.g. the Google Privacy Policy).

Service providers may receive standard technical information such as IP addresses as part of HTTPS requests. Refer to each provider’s policy for details.

Remote code

The Extension does not fetch and execute remote JavaScript or other executable code. API responses are treated as data (e.g. JSON) and processed only by code shipped inside the Extension package, consistent with Manifest V3.

Permissions (why they exist)

  • activeTab — Read selected text, URL, and title from the active tab right after you invoke the Extension.
  • alarms — Periodically refresh cached Backlog master data.
  • clipboardRead / clipboardWrite — Support selection capture via copy flows and pasted content where applicable.
  • contextMenus — Provide context-menu entries such as creating an issue.
  • scripting — When needed, run minimal in-tab logic on user action to obtain selected text.
  • sidePanel — Show the issue form in Chrome’s side panel.
  • storage — Save and load settings, keys, drafts, and caches.
  • windows — Open the issue UI in a popup window when that mode is enabled.
  • Content scripts (declared in the manifest) — Assist with reading selection on matching pages. Chrome’s install prompt may describe broad site access; that reflects where scripts may run. The Extension does not request broad <all_urls> host_permissions for arbitrary network access.
  • Host permissions — Communicate with your Backlog space and, if configured, OpenAI and Google (Gemini) API endpoints.

Data retention

Local data remains until you clear extension data, uninstall the Extension, or change it inside the Extension. Issues you create are retained under your Backlog workspace settings and agreements.

Children

The Extension is not directed at children, and we do not knowingly collect personal information from children.

Changes to this policy

We may update this Privacy Policy when the Extension’s behavior or requirements change. The effective date at the top will be revised when updates are published.
