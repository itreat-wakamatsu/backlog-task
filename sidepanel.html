AI自動入力

選択テキストとページのURL・タイトルから、課題の件名・詳細・担当者・期日を自動入力します。OpenAI と Gemini の API キーはそれぞれ別に保存・管理されます。

プロバイダ

AI APIキー

OpenAI の API キーを設定すると、課題の内容を自動入力できます。キーは拡張機能内にのみ保存され、OpenAI の API に送信されます。

現在選択中のプロバイダ（OpenAI / Gemini）用のキーだけを入力・保存します。切り替え時はそれぞれのキーを別途設定してください。
